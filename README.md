# Veronika Albero — портфолио

Все файлы в одной папке, без подпапок.

## GitHub → Vercel
1. Загрузите **все файлы этой папки** в корень репозитория (GitHub → Add file → Upload files → перетащить всё → Commit).
2. Vercel → Add New → Project → Import репозитория.
3. Framework Preset: **Other**. Build / Output / Install Command — пусто.
4. Deploy. Каждый commit в main обновляет сайт.

## Важно
- Не переименовывайте файлы и не раскладывайте по папкам — пути прописаны в index.html.
- support.js и image-slot.js обязательны.
- Домен: Vercel → Project → Settings → Domains.
